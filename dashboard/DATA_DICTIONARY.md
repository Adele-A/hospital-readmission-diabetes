# Dashboard data dictionary

Star-schema CSVs in `dashboard/data/`, generated by `python -m src.export.powerbi`.
All files are UTF-8 with `.` as the decimal separator and `,` as the field
separator. Fact tables link to dimension tables on the named keys.

**Important:** `predicted_risk` and `high_risk_top20` in `fact_encounters` are
populated **only for the test split** (out-of-sample). Training rows are blank, so
any risk visual must filter `split = "test"`. Descriptive visuals (readmission
rate by characteristic) may use the whole cohort.

---

## fact_encounters.csv — grain: one row per cohort encounter

| column | type | description |
| --- | --- | --- |
| encounter_id | integer | Encounter identifier (unique row key). |
| split | text | `train` or `test` (patient-grouped 80/20 hold-out). |
| age_group | text | Age band, 10-year (dataset's own banding). Links to `dim_age_group`. |
| gender | text | `Female` / `Male` (Unknown/Invalid already excluded). |
| race | text | Reported race; `?` shown as `Missing`. Use cautiously. |
| admission_type_id | integer | Admission type code (see `IDS_mapping.csv`). |
| discharge_group | text | Coarse discharge disposition: Home / SNF-ICF / Transfer / Other. |
| diag_1_group | text | Primary-diagnosis ICD-9 group (Strack scheme). Links to `dim_diag_group`. |
| prior_inpatient_grp | text | Prior inpatient visits bucket: `0`,`1`,`2`,`3+`. |
| a1c_result | text | `None` (not measured), `Norm`, `>7`, `>8`. |
| change | text | `Ch` if any diabetes medication changed, else `No`. |
| diabetes_med | text | `Yes` if any diabetes medication prescribed. |
| insulin | text | Insulin status: `No`/`Down`/`Steady`/`Up`. |
| time_in_hospital | integer | Length of stay in days (1–14). |
| number_inpatient | integer | Prior inpatient visits in the year before. |
| number_emergency | integer | Prior emergency visits in the year before. |
| number_diagnoses | integer | Number of diagnoses recorded. |
| readmitted_lt30 | integer | **Target**: 1 if readmitted < 30 days, else 0. |
| predicted_risk | decimal | Gradient-boosting predicted probability (**test rows only**). |
| high_risk_top20 | integer | 1 if in the top-20%-risk operating point (**test rows only**). |

## fact_metrics.csv — grain: model × metric

| column | type | description |
| --- | --- | --- |
| model | text | Model or baseline name. Links to `dim_model`. |
| metric | text | `ROC-AUC`, `PR-AUC`, or `Brier`. |
| value | decimal | Point estimate on the test set. |
| ci_low / ci_high | decimal | 95% patient-cluster bootstrap interval. |
| split | text | `test`. |

## fact_calibration.csv — grain: model × calibration bin

| column | type | description |
| --- | --- | --- |
| model | text | `Logistic regression` or `Gradient boosting`. |
| bin | integer | Quantile bin index (0–9). |
| n | integer | Encounters in the bin. |
| mean_predicted | decimal | Mean predicted probability in the bin. |
| observed_rate | decimal | Observed readmission rate in the bin. |

## fact_threshold_table.csv — grain: model × operating point

| column | type | description |
| --- | --- | --- |
| model | text | `Gradient boosting` or `Logistic regression`. |
| operating_point | text | `top10`, `top20`, or `sens~50%` (thresholds chosen on train CV). |
| threshold | decimal | Probability cut-off applied to test. |
| flagged / flagged_per_1000 | integer / decimal | Encounters flagged high-risk. |
| sensitivity, specificity, ppv, npv | decimal | Confusion-matrix rates on test. |
| tp, fp, tn, fn | integer | Confusion-matrix counts. |

## fact_subgroup_performance.csv — grain: dimension × subgroup

| column | type | description |
| --- | --- | --- |
| dimension | text | `age_group`, `sex`, or `race`. |
| subgroup | text | Subgroup level. |
| n | integer | Test encounters in the subgroup. |
| positive_pct | decimal | Observed readmission rate (%). |
| roc_auc | decimal | Gradient-boosting ROC-AUC (blank if n < 100 or single class). |
| calib_intercept / calib_slope | decimal | Cox calibration (blank if undefined). |

## Dimension tables

- **dim_model.csv** — `model`, `is_baseline`.
- **dim_age_group.csv** — `age_group`, `sort_order` (for correct axis ordering).
- **dim_diag_group.csv** — `diag_1_group`, `sort_order`.
